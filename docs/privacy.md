# MeetScribe 隐私政策

更新日期：2026 年 10 月 29 日

本政策说明 MeetScribe Chrome 扩展如何处理数据。MeetScribe 用于 Google Meet 和 Microsoft Teams 网页会议的本地录音、实时字幕及会后转写。扩展没有开发者运营的后端、广告或分析追踪服务。

## 处理哪些数据

- **会议音频和通信内容**：用户主动开始录制后，扩展获取当前会议标签页音频，以及用户启用并授权的麦克风音频，生成录音和字幕。
- **会议元数据**：会议标题、会议页面网址、开始和结束时间、转写状态、语言提示和说话人编号。扩展不收集其他网页的浏览历史。
- **设置和身份验证信息**：用户自行填写的 Soniox API key、语言和转写设置、麦克风设备选择及导出偏好。API key 用于直接向 Soniox 验证身份，不发送给扩展开发者。
- **本地排错日志**：运行状态、错误和服务响应等技术信息。日志可能包含会议标题、网址、时间、用户设置和错误详情；日志中的密钥字段会被遮盖。日志不会自动上传给开发者，用户可以自行导出。

这些数据仅用于录音、转写、回放、搜索、导出和故障排查，不用于广告、数据交易、信用评估或放贷。

## 数据保存在哪里

设置和 Soniox API key 保存在本机的 `chrome.storage.local`，API key 未另外加密。会议录音、字幕、元数据和日志保存在扩展的本地 IndexedDB 中。当前录音的临时状态保存在 `chrome.storage.session` 中。

扩展开发者不会自动收到上述数据。用户选择导出的录音、字幕或日志保存在本机下载目录；用户自行分享这些文件时，接收方会得到其中的内容。

## 何时向 Soniox 发送数据

- 未配置 Soniox API key 时，扩展可以仅录音，录音仍保存在本机。
- 用户配置 API key 并开始实时转写时，扩展将会议音频通过加密 WebSocket 直接发送至 Soniox，并接收转写结果。语言提示、转写上下文词条及用户启用的说话人区分、翻译等设置也会发送给 Soniox。
- 用户请求会后补转或整场重转时，扩展通过 HTTPS 向 Soniox 上传对应录音，创建转写任务并获取结果。
- 用户点击测试 API key 时，扩展会向 Soniox 发起经过身份验证的请求。

Soniox 是用户自行选择并提供 API key 的转写服务，其数据处理和保留规则适用 [Soniox 隐私政策](https://soniox.com/policies/privacy-policy)及用户与 Soniox 的服务安排。网络请求也会使 Soniox 获得建立连接所需的信息，例如 IP 地址。

异步转写成功获取结果后，扩展会请求删除 Soniox 上的转写任务和上传文件；部分失败流程也会执行清理。如果网络中断、页面关闭、任务未完成或删除请求失败，远端数据可能仍然存在。本地删除会议或卸载扩展不会保证删除 Soniox 上尚未清理的数据，用户可通过自己的 Soniox 账号管理这些数据。

## 保留与删除

- 本地会议录音和字幕保留到用户在历史页删除会议，或卸载扩展。请在删除或卸载前导出需要保留的数据。
- 用户可在设置页替换或清空 API key，修改转写设置，并在录音过程中停止录制。
- 本地日志按程序清理规则保留最近约 14 天，并限制最多约 50,000 条；清理在扩展运行时执行，具体时间取决于浏览器运行状态。
- 卸载扩展会清除其本地数据，但不会删除已导出到下载目录的文件。

## 用户控制与联系

录音由用户通过扩展按钮或快捷键主动开始。用户应在录音和转写前告知参会者，并取得适用要求下的同意。

隐私问题可通过 Chrome 商店详情页中的发布者联系邮箱，或 [MeetScribe 项目反馈页](https://github.com/humiaozuzu/MeetScribe/issues)联系维护者。项目反馈页公开可见，请勿在其中提交 API key、私人录音或含敏感内容的日志。

如果扩展的数据处理方式发生变化，本政策将随之更新。
